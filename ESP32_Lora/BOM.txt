	    SENSOR BUS (new):

    INA226: VCC→3.3V, SDA→GPIO21, SCL→GPIO22
    DS18B20: VDD→3.3V, DQ→GPIO4 (4.7kΩ pull-up to 3.3V), GND→GND


    FAN CIRCUIT (new — 3 components):

    5V rail → FAN(+) → [Fan] → FAN(-) → AO3400 DRAIN
                                       AO3400 SOURCE → GND
    GPIO16 → [100Ω] → AO3400 GATE
                       [10kΩ] → GND (pulldown)
    1N5819: cathode→5V, anode→AO3400 DRAIN (flyback)


    Fan Logic (software):

    IF Vbus ≥ 12.0V AND DS18B20 ≥ 40°C → GPIO16 HIGH → fan ON
    IF Vbus < 12.0V                    → GPIO16 LOW  → fan OFF (don't touch battery)
